# 模板库

这里放写作过程中可复用的结构化模板，目标是减少跑偏、支线失控和节奏失衡。

## 使用顺序

1. `chapter-intent-template.md`
2. `mainline-subline-control-template.md`
3. `context-pack-template.md`
4. `chapter-rhythm-checklist-template.md`
5. `hook-ledger-template.md`
6. `review-template.md`

## 原则

- 每个模板只解决一种问题。
- 先填空，再写正文。
- 发现冲突先记录，不要边写边改正史。
