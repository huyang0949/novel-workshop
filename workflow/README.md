# workflow

这里放小说写作过程中的流程文件、模板、审稿记录、候选推演和参考拆解，不放小说正史正文。

## 目录

| 目录 | 用途 |
|---|---|
| [working/](working/) | 当前写作任务、章节意图、上下文包和可复用模板 |
| [reviews/](reviews/) | 章节审稿报告、修订建议 |
| [forecasts/](forecasts/) | 候选剧情推演，不直接进入正史 |
| [model/](model/) | 作品拆解、参考分析和辅助材料 |

## 使用顺序

`working -> drafts -> review -> revision -> canon`
