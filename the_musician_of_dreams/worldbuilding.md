# 世界观设定文档

## 项目定位

本书是一部现实感很强的现代文娱音乐小说。

故事核心是男主在四十五岁意外死亡后，重生回重点音乐大学大三时期。他前世因为家庭安排进入父母的金融公司工作，在高压生活中逐渐放弃音乐，最终在离婚当天遭遇意外死亡。重生后，他决定重新享受生命，重新走上音乐道路。

小说主线不是娱乐圈成名，而是男主作为音乐人、作曲人、演奏家不断提升音乐能力，最终成长为真正优秀的音乐家。娱乐圈、直播综艺、影视游戏配乐、演唱会和音乐节都是男主音乐才能被看见的舞台。

## 世界基调

- 时代背景：近现代都市，移动互联网、直播、短视频、流媒体、影视游戏产业成熟。
- 行业氛围：现实感强，作品质量、业内资历、商业价值和大众传播并行。
- 叙事气质：克制、细水长流、现实向，不靠夸张打脸推进。
- 核心主题：重活一次，把被现实压垮的音乐理想重新拾回来。

## 男主基础设定

- 身份：重点音乐大学音乐系学生，重生时为大三。
- 家庭：父母经营金融公司，家境优渥，是富二代。
- 居住状态：大学期间在校外租房，用作生活和音乐创作空间。
- 前世经历：毕业后因家庭安排进入父母公司从事金融相关工作，压力巨大，逐渐放弃音乐。
- 重生节点：四十五岁当天，与妻子办理离婚手续后遭遇意外，当场去世，随后穿越回大学大三。
- 今生目标：享受生命，享受音乐，重新走上音乐道路。

## 男主人设

男主是才华横溢型音乐人。

外在表现：

- 低调谦和。
- 话不多。
- 不主动抢镜。
- 做事稳定。
- 对不懂音乐的人也有耐心。

内在特质：

- 内心想法很多。
- 有点闷骚。
- 经常在心里吐槽，但不轻易说出口。
- 因为前世经历，对名利、关系和人情世故更清醒。
- 不喜欢被流量裹挟，但能理解商业逻辑。

音乐特质：

- 以纯音乐、器乐、配乐、主题动机和现场演奏为核心。
- 不依赖歌词表达。
- 作品重视情绪、画面感、结构和听众共鸣。
- 擅长通过旋律和编曲写出人物、场景、记忆和遗憾。

## 音乐行业结构

这个世界的音乐行业分为以下几条主要线：

- 学院派：音乐学院、专业课程、毕业音乐会、比赛、演奏厅。
- 幕后制作：作曲、编曲、录音、制作人、音乐总监。
- 商业发行：娱乐公司、歌手、偶像团体、音乐平台、宣发资源。
- 直播综艺：音乐训练、直播讨论度、排名考试、舞台展示。
- 影视游戏配乐：电视剧、电影、游戏章节、角色主题曲、场景 BGM。
- 现场演出：演唱会、音乐节、个人音乐会、跨界舞台。

男主最初从幕后制作线进入行业，随后通过毕业音乐会和直播综艺被大众认识，但主业始终是音乐创作与演奏。

## 作品传播逻辑

男主的爆火不依赖人设硬捧，而依赖作品质量与传播场景叠加。

传播路径：

1. 完成 demo。
2. 向娱乐公司、制作人或音乐工作室投稿。
3. demo 被采纳，成为歌手作品或项目配乐。
4. 作品上线后获得市场反馈。
5. 男主积累三四首热曲，形成业内资历。
6. 毕业音乐会现场视频流传网络。
7. 被娱乐公司经理推荐参加直播综艺。
8. 在综艺中通过创作、演奏、配乐和日常表现持续破圈。

## 音乐描写原则

由于男主主要创作纯音乐，正文不依赖歌词展示才华。

重点写法：

- 写听众听到音乐后的沉默、失神、回忆和情绪变化。
- 写音乐带来的画面感、空间感和情绪流动。
- 通过侧面描写突出男主才华。
- 通过导师、歌手、观众、普通听众、业内制作人的反应建立可信度。
- 技术细节可点到为止，不让专业术语压过阅读体验。

可写的听众反应：

- 听完后忽然想起某个亲人。
- 在旋律中回忆起大学、雨夜、离别、故乡。
- 现场演奏结束后，全场短暂安静。
- 有人说不清为什么难过，却被音乐击中。
- 专业人士从结构、配器、情绪完成度上认可男主。

## 直播综艺设定

综艺核心形式是音乐夏令营。

节目形态：

- 直播合宿。
- 音乐训练。
- 定期作业。
- 排名考试。
- 舞台展示。
- 录播精剪与直播讨论并行。

参与者构成：

| 类型 | 作用 |
| --- | --- |
| 新人偶像 | 带来粉丝、舞台表现和流量冲突 |
| 跨界艺人 | 带来综艺效果和学习反差 |
| 网红歌手 | 带来网络话题和野路子音乐理解 |
| 专业音乐人导师 | 提供权威评价和训练体系 |
| 男主 | 以素人身份加入，但专业能力突出 |

节目任务类型：

| 作业类型 | 示例 |
| --- | --- |
| 主题创作 | 夏天、离别、故乡、第一次心动、雨夜 |
| 影视配乐 | 给电视剧、电影、纪录片片段配乐 |
| 游戏配乐 | 给战斗、古风城镇、角色登场、剧情转折写 BGM |
| 即兴创作 | 抽关键词，当场写一段旋律 |
| 改编作业 | 将流行歌改成钢琴曲、弦乐版、国风版、电子版 |
| 团队合作 | 男主负责作曲或编曲，其他人负责演唱或表演 |
| 考试环节 | 听音、节奏、编曲、现场演奏、限定时间创作 |

综艺篇幅规划：

- 综艺阶段是长篇重点，可持续数百章节。
- 男主会先后参加多个不同综艺。
- 第一档综艺负责完成素人破圈。
- 后续综艺负责扩大影响力、展示不同音乐能力和人际关系。

## 综艺中的男主表现

综艺阶段除了音乐创作主线，也重点刻画男主日常风格和为人处世。

反差表现：

| 表面 | 实际 |
| --- | --- |
| 看起来安静 | 心里已经把局势分析完了 |
| 不怎么说话 | 一开口能点出核心问题 |
| 不主动争排名 | 每次作业成绩都很高 |
| 像普通素人 | 已经是写出热曲的幕后作曲人 |
| 不太会营业 | 偶尔一句话反而形成节目效果 |

可以反复使用的综艺看点：

- 男主熬夜改编曲子，但嘴上说只是随便试试。
- 面对导师夸奖时很平静，心里却默默松一口气。
- 帮其他选手调整作品，不抢功劳。
- 被直播镜头拍到生活细节，观众发现他比想象中更有趣。
- 在团队任务中用最少的话稳住局面。
- 遇到故意炒作的人，不正面冲突，但用作品压住场面。

## 娱乐公司长线合作

男主与娱乐公司的合作不是一次性情节，而是贯穿到综艺阶段之后的长线事业线。

合作内容：

- 给旗下歌手写歌。
- 为偶像团体提供主打曲或舞台改编。
- 参与歌手专辑企划。
- 为演唱会设计编曲、串场音乐或特别舞台。
- 协调音乐节现场表演内容。
- 为公司投资或合作的影视、游戏项目提供配乐。

娱乐公司经理的作用：

- 最初发现或接纳男主的 demo。
- 推动男主成为合作作曲人。
- 在男主有三四首热曲后，推荐他参加直播综艺。
- 是男主从幕后走向大众视野的重要桥梁。

## 感情线设定

女主在男主进入综艺阶段之前出场。

女主基础设定：

- 身份：初中语文老师。
- 性格：活泼开朗、真诚、话痨、幽默，行动力强。
- 爱好：二次元、古装、传统文化、古风游戏。
- 外在气质：颜值中上，不靠惊艳感吸引男主。
- 吸引男主的核心：率真、好玩、情绪鲜活，能把日常生活过得很有趣。
- 情感基调：慢热、自然、长期稳定。
- 作用：不是事业挂件，而是男主重新享受生活的重要象征。

相识场景：

- 男主为一款古风游戏的新章节做了配乐。
- 游戏方邀请男主前往动漫节或线下展会参观。
- 女主正好是这款游戏的爱好者，穿着古装前来打卡拍照，并主动拉着朋友一起参与活动。
- 女主听到新章节配乐后被触动。
- 她不知道作曲人就在身边，说出对这段音乐的真实感受。
- 男主因此注意到她。

可用初遇台词方向：

> 这段不像在写江湖，像是在写一个人终于回家了。

这句话可以成为男主被女主吸引的起点，因为她听懂了音乐中真正想表达的东西。

## 感情线推进

这条感情线不走强冲突路线，主要依靠长期相处、日常沟通和彼此陪伴推进。

推进方式：

- 初识阶段，女主先被音乐打动，男主先被她的真实表达吸引。
- 熟悉阶段，女主会主动找男主聊天，分享学校日常、古风游戏、动漫活动和生活趣事。
- 相处阶段，女主会拉着男主一起参加古装 cosplay、展会打卡、轻松活动或线下见面。
- 男主表面安静，实际会记得她的兴趣点和说过的小事，也会用作品回应她。
- 男主参加综艺或出国留学期间，双方都会保持稳定联络，不会因为距离断掉关系。
- 这段关系的底色是互相理解，而不是单向仰望。

女主的功能不是被男主拯救，而是把男主重新带回有趣、鲜活、有人一起分享的生活里。

## 求婚与收束

在留学期末，男主会完成一首古风曲。

这首曲子可以承担两层作用：

- 作为他留学阶段音乐成长的总结。
- 作为送给女主的求婚作品。

建议的收束方式：

- 男主在毕业后，将这首古风曲正式送给女主。
- 曲子的情绪方向可以偏向同行、归家、把未来交给彼此。
- 求婚场景不需要铺张，重点放在男主一贯克制、认真，但这一次明确表达心意。
- 女主的回应要符合她的性格，直接、真诚、开心得很明显，会比煽情更有辨识度。

这条感情线的最终效果，是让男主在完成事业成长的同时，也真正拥有一个愿意分享生活的人。

## 海外求学线

在综艺阶段接近结束时，男主通过国外音乐大学的研究生入学申请，随后前往国外继续学习。

这一阶段的作用不是让男主脱离主线，而是让他的音乐视野和创作半径进一步扩展。

海外阶段的核心内容：

- 日常上课。
- 交作业。
- 参加 workshop、排练、讲评课和小型展示。
- 因为和娱乐公司的合同，定期直播自己的生活和创作小样。
- 保持与国内娱乐圈、综艺和配乐项目的联系。

课程节奏可以采用接近现实的音乐研究生模式，不必写得过于教条：

- 每周有固定主课和小课。
- 以个人作品、专题作业、课堂展示和导师反馈为主。
- 平时要大量练习、改稿、排练和听同学作品。
- 节奏不像本科那样满课，更强调自主创作和阶段性交付。
- 常会出现临时加课、排练、试奏、masterclass 或项目汇报。

这种安排适合写出男主一边学习、一边持续产出作品的状态，也方便保留他的职业连贯性。

## 海外乐队线

男主到国外后，会认识新的同学。

出于兴趣，他会和这些同学组一个乐队，主要用于：

- 练习合奏与现场感。
- 体验不同音乐文化的协作方式。
- 在国外音乐节或校园活动中进行演出。
- 为男主提供新的创作灵感和人际关系线。

这个乐队只是兴趣性质，不会真的走向正式出道。

它的叙事功能在于：

- 丰富男主的海外日常。
- 展示男主不是只会写曲，也能和别人一起“玩音乐”。
- 给国外篇章增加现场表演和团队合作的内容。

## 国内往返与综艺延续

虽然男主去了国外，但他不会彻底切断国内事业线。

可以保留以下安排：

- 依靠合同或合作关系，定期直播自己的日常生活和小样创作。
- 回国参加部分录播综艺。
- 继续参与公司项目、配乐项目和特邀合作。
- 在国内外之间往返，让事业线保持连续。

这样可以避免海外篇章和国内主线割裂，也能让男主始终维持一定曝光度。

## 电视剧跨界支线

男主后期可以接一条电视剧跨界演出支线。

设定方向：

- 男主出演电视剧中的一个配角。
- 同时参与这部电视剧的配乐制作。
- 让他以“演员 + 配乐人”的双重身份进入另一类娱乐项目。

这条线的作用：

- 扩展男主在行业内的多面性。
- 为影视圈和音乐圈的交叉合作提供素材。
- 增加男主在大众眼中的真实感，而不是单一的音乐机器。

这条支线不需要把男主写成职业演员，重点仍然是音乐。
电视剧演出只是跨界尝试，最终仍要回到作曲、配乐和现场演奏主线。

## 当前已确定的核心规则

- 世界观使用现实感强的现代文娱世界。
- 男主重生回大三，不是从零开始，而是带着前世阅历重新拾起音乐。
- 男主家境优渥，校外租房创作合理。
- 前期通过 demo 投稿进入娱乐公司，成为幕后作曲人。
- 给娱乐公司写曲是长线，直到综艺阶段仍持续合作。
