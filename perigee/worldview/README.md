## 一页总结

- 核心设定是“黑石锚点 + 蓝光辐射 + 超级月亮窗口 + 觉醒/异化并存”。
- 所有异能共用同一套蓝光来源，不存在独立魔法体系。
- 能力必须满足：单一核心变量、明确作用对象、可观测痕迹、可克制方式、有代价。
- 超级月亮既是觉醒窗口，也是灾变窗口，电子系统会周期性大规模失效。
- 觉醒者并不是天然英雄；力量增长会同时带来侵蚀、失控和社会资源争夺。
- 人类、动物、植物共享同源机制，但感知方式和表现层不同。

## 设定骨架

### 1. 源头
- 黑石是锚点，不是普通天体事件。
- 蓝光是力量的载体，也是污染和侵蚀的来源。
- 地表热点只是在动态环境中更容易沉积和转化蓝光，不是固定“圣地”。

### 2. 觉醒
- 灵感决定能否感知。
- 意愿决定能力显化方向。
- 觉醒不是进化神话，而是被力量影响后的副产物。

### 3. 能力
- 形态、运动、感知、生理、物质、精神、共生、场域是主分类。
- 元素系只是高可视化表现层，不是独立底层规则。
- 每个正式能力都要写成契约，而不是只写名字和效果。

### 4. 社会
- 异能会带来职位、收入、医疗、住房和组织资源差异。
- 主要冲突来自同类竞争、制度控制和利益越线。
- 官方机构、跨国组织和地下组织都在争夺解释权与资源。

### 5. 终局
- 白色空间是人类意识对“同时读取一切因果”的翻译界面。
- 祂完成观察后离开，正篇结束，大部分主动异能衰退。

## 需要继续确认的点

1. 主舞台城市和第一卷灾变热点具体落点。
2. 新月教在第一卷里是公开对手还是只露出极端分支。
3. 深潜会是否已经确定祂最终会离开。
4. 第一卷事件是否完全公开到社会层面。
5. 蓝磁灾变下，哪些机构能维持最低限度运转，哪些要退回手工体系。
6. “扩宽容器”是否只保留为终局异常，不进入常规升级。
7. 现有样本能力里，是否需要再收紧“多变量合并”的写法。
