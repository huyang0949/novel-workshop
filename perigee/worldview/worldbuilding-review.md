# 世界观审查与优化底稿

> 本文不替换原始 `worldbuilding.md`，用于整理规则、标记逻辑问题，并作为后续修订的依据。

## 一、总体判断

核心卖点清晰：月球黑石作为锚点，蓝光带来觉醒，能力由生物的意愿显化，力量越强心智侵蚀越深，最终指向降临。人类、动物、植物三种觉醒路径也形成了很好的都市灾变层次。

当前最大问题不是创意不足，而是**权威层级不清、规则边界不够硬、章节结构失序**。如果不先统一，后续会出现能力临时加规则、政府反应失真、等级互相矛盾等问题。

## 二、必须先修正的逻辑问题

### 1. 觉醒条件与灵感等级矛盾

文档写“必须拥有较高灵感”，但 Lv.1 钝感者也可以在超级月亮下觉醒；动物被定义为低灵感，植物又被定义为几乎零灵感却几乎必然觉醒。

**建议统一为：**

- 觉醒需要“可用的感知通道 + 足够的能量 + 强烈意愿/本能”。
- 人类的感知通道由灵感决定；Lv.0 没有通道，Lv.1 只能直视超级月亮，Lv.2 以上可被月光直接激活。
- 动物不是“灵感更高”，而是拥有低效但可被蓝光强制打开的视觉通道，本能补足意愿效率。
- 植物不使用人类灵感体系，采用“原初共振”规则；充能慢、阈值低，因此长期觉醒率高。

这样三类生物使用同一套底层公式，但参数不同，不再互相打架。

### 2. 能量等级上限表述不一致

Lv.1 的上限写成“炼体巅峰”，而其他段落又使用“活化、升华、饱和、超限”。必须明确 Lv.0-Lv.4 灵感与一至五阶能量的对应关系。

**建议固定为：** Lv.0 不可觉醒；Lv.1 上限一阶·炼体；Lv.2 上限二阶·活化；Lv.3 上限三阶·升华；Lv.4 理论上可到四阶·饱和，只有特殊条件才能进入五阶·超限。Lv.4 的“理论无上限”应删除，否则会削弱终局门槛。

### 3. 五阶·超限与降临条件重复且互相冲突

外部评级 α 说“饱和以上 + 锚化”可能降临，但终局条件要求“五阶·超限 + 超级月亮 + 四阶锚化”。

**建议规定：**

- α 级只是政府的未知风险标签，不是降临判定。
- 降临硬条件固定为：Lv.4、五阶·超限、四阶·锚化、超级月亮蓝光覆盖。
- “锚化”是侵蚀状态，不等于能量阶位；两者不能互相替代。

### 4. “吸收他人能量”需要独立规则

击杀或吞噬觉醒者即可掠夺能量，会直接改变社会治安、黑市、组织目标和主角战斗逻辑，但目前没有说明触发方式、掠夺比例、距离、尸体时限和失败后果。

**建议补全为：**只有五阶前的特定能力或锚化个体才能执行；必须接触并持续一段时间；只能吸收残留能量的一小部分；同时继承对方一段记忆或侵蚀症状；普通觉醒者无法靠“吃掉对方”升级。若不想让世界变成刷怪升级，应删除“吞噬”字样，改为极少数特殊系能力的危险效果。

### 5. 超级月亮的天文规则需要封口

12 月 24 日和 1 月 22 日相隔 29 天，作为连续朔望月合理，但“满月 + 近地点”并不天然等于超级月亮且通常不会每月固定发生。建议明确这是黑石造成的“异常近地点窗口”，并给出窗口周期、持续时长、全球是否同步、云层和地下空间是否阻挡。

### 6. 蓝光的传播与黑石辐射不完全一致

黑石近距离会熔毁电子设备和生物，但月面反射后的蓝光又能成为觉醒通道。需要区分“未滤过辐射”和“经锚点/月面调制后的低危蓝光”，否则探月车失败与地表人类大规模存活难以同时成立。

### 7. 能力显化边界过于宽松

“你最想要什么”容易造成任何愿望都能变成能力。建议增加四条硬限制：

1. 只能沿宿主已有生理结构或可观测对象显化，不能凭空创造物质。
2. 目标越抽象，能量消耗和侵蚀越高。
3. 作用范围、持续时间、精度三者至少牺牲一项。
4. 觉醒瞬间只确定一个核心意愿，后续只能在同一核心上变形，不能随意换系。

### 8. 终局段落的“全地球替换”要定义状态

目前 11.3-11.5 更像终局文学草稿，而不是可供前文引用的规则。请标记为“终局假说/作者确定的结局”之一，并明确：是否存在幸存者、是否可逆、叙述者是谁、物体诉说是客观事件还是主观幻象。

### 9. 文档结构和编号失序

“第十三节”结束后又出现“11.1 降临条件”，并且中间提前出现“截至 2031 年 1 月已确认”的结语。建议调整为：

1. 基调与核心源头
2. 时间线与超级月亮
3. 觉醒总规则
4. 人类、动物、植物
5. 能力与等级
6. 侵蚀与降临
7. 政府、法律、市场
8. 阵营组织
9. 叙事入口与开篇建议
10. 待确认问题与终局草稿

## 三、建议补充的内容

### A. 数值与分布

- 全球人口中的灵感等级比例、觉醒率和死亡率。
- 第一波、第二波各自的规模，以及不同地区差异。
- 超级月亮持续多久，觉醒通常在窗口内还是窗口后发生。
- 觉醒者是否会传染，植化感染的概率、潜伏期和检测方式。

### B. 现实后果

- 医疗系统如何处理再生、矿化、蓝光辐射和精神症状。
- 觉醒者是否仍受劳动法、刑法、学校制度约束。
- 交通、能源、保险、军警装备和城市基础设施的具体变化。
- 普通人如何验证网络视频，政府是否隐瞒黑石和死亡数据。

### C. 能力与战斗规则

- 每类能力的有效距离、冷却/疲劳、误伤风险和可被什么手段克制。
- 能量耗尽后的症状，以及侵蚀是否会因停止使用而减缓。
- 精神系能力的抗性来源，避免“记忆改写”破坏所有悬疑。
- 植物和动物能力如何被侦测、隔离、驯化或消灭。

### D. 组织与剧情接口

- UNSAD、JIC、特事司三者的汇报链和权限边界，避免机构功能重复。
- 每个阵营的资源来源、招募方式、核心人物和内部派系。
- 归序者“封禁蓝光”具体能做到什么；庇护所如何证明自身有效；深潜会为何不被政府清除。
- 新月教在公开社会中的合法性、资金来源和成员规模。

### E. 主角入口

开篇建议已经有了，但还缺主角的职业、初始灵感等级、核心意愿、第一次能力失控、与至少一个组织的利益冲突。没有这些，双线开篇仍停留在镜头设计，无法转成第一卷主线。

## 四、建议采用的“世界规则总表”

后续写作时，把以下内容视为唯一硬规则，其余内容标记为“推测”或“待确认”：

| 规则 | 统一表述 |
|---|---|
| 力量来源 | 黑石是不可名状存在在本宇宙的锚点；地表接收到的是经月面调制后的低危蓝光 |
| 人类觉醒 | 可用感知通道、足够能量、强烈核心意愿三者同时满足 |
| 动物觉醒 | 低效视觉通道 + 本能意愿；不提升灵感等级 |
| 植物觉醒 | 独立的原初共振；充能慢、阈值低，不套用人类灵感等级 |
| 能量阶位 | 炼体 → 活化 → 升华 → 饱和 → 超限 |
| 灵感作用 | 决定感知门槛、容器上限和侵蚀系数；人类天生固定 |
| 掌控作用 | 决定精度和误伤，不改变能量总量 |
| 侵蚀作用 | 不可逆，变强与失去自我是同一条路径的两端 |
| 降临 | Lv.4 + 五阶超限 + 四阶锚化 + 超级月亮覆盖 |

## 五、修订优先级

1. 先重排章节编号，拆分“硬规则、世界现状、终局草稿、叙事建议”。
2. 再确定灵感/能量/侵蚀三套等级的映射表。
3. 决定是否保留“吸收他人能量”和“植化感染”作为正式机制。
4. 补齐超级月亮周期、觉醒统计和政府权限。
5. 最后根据主角设定，把能力限制和第一卷冲突写成可执行的章节约束。

## 六、目前不建议直接定死的内容

- 祂的真实名称和完整来源。
- 终局白色空间究竟是现实、梦境还是宇宙重置。
- 深潜会掌握的其他锚点是否真实存在。
- “绿色泰坦”是否必然出现。

这些内容适合作为悬念或多方推测，过早写成事实会削弱克苏鲁未知感。

## 七、已确认的修订方向

以下内容已根据作者决策升级为当前工作假设：

1. **取消能量掠夺**：觉醒者不能通过击杀、吞噬或直接接触其他觉醒者获取能量。能量来源限定为月光、超级月亮、高密度共鸣区，以及宿主对蓝光的生理转化。
2. **保留高密度共鸣区**：地质结构、地下水、根系网络或大量生命聚集的地点会提高蓝光沉积和转化效率，成为资源与剧情冲突点。
3. **三类生命同源觉醒**：人类、动物、植物共享“感应度 × 意志度 × 容纳度 × 累积剂量”的底层机制；差别来自神经系统、群体本能、根系/细胞网络等承载方式，而不是三套互不相容的规则。
4. **植物网络有限行动**：植物可以通过根系、菌根和化学信号形成有限的行动网络，但不具备完整人格，不应直接写成一个会正常对话的人类角色。
5. **终局动机**：祂降下能量是出于好奇和观测，不是征服、惩罚或救世。完成对地球生命与文明的观察后，祂会离开。
6. **故事终点**：正篇在祂离开时结束，不进入“离开后的新世界”长篇叙事。离开后的影响只通过尾声、记录或最后一个镜头短暂呈现。

### 7.1 结局余波的推荐处理

为了同时满足“故事完结”和“前文后果真实存在”，推荐采用：

- 蓝光输入停止，新的觉醒和能力成长终止；
- 大部分主动异能逐步衰退或失效；
- 已发生的生理变异、伤痕、记忆损伤、植物生态改变无法完全恢复；
- 黑石失去可测响应，是否仍在月面保持未知；
- 最后一幕只留下一个极弱、无法确认来源的蓝色信号，不以此开启续篇。

这样不需要继续描写“能力者社会”，但能证明祂离开并没有把一切简单地复原。若希望结局更冷酷，也可以让所有异能在离开瞬间消失，只保留不可逆的身体与社会后果。
