# 能力契约表

> 本表是世界观中所有异能的设计约束。能力名称和表现可以扩展，但不能绕过本表的底层限制。

## 一、统一底层规则

1. 所有能力都来自同一种蓝光能量，不存在独立的魔法、精神力或其他能源。
2. 能力只能把能量转化为具体效果，不能凭空创造能量、信息、物质或生命。
3. 每个能力只能有一个核心作用对象和一个核心变量。复合能力必须达到更高能量阶位，并承担额外侵蚀。
4. 能力越抽象，误差越大、消耗越高、持续时间越短，越容易失控。
5. 能力的表现由觉醒者的核心意志决定，但核心意志不能随意更换。成长是同一能力的深化，不是自由转职。
6. 能力必须留下可观察痕迹：蓝光变化、生理负担、温度/声音异常、材料损伤或精神症状至少存在一种。
7. 任何能力都必须存在至少一种可靠的外部克制手段。没有代价、没有痕迹、没有克制的能力不得加入正式设定。
8. 能力不自动附赠反应速度、耐久、再生或枪械防御。只有契约明确写明的身体变化才有效。
9. 防御能力必须注明覆盖部位、启动时间、防御方向、单次与连续承受上限，并区分穿刺、冲击、爆炸、燃烧、低温和化学伤害。
10. “刀枪不入”“免疫物理伤害”“绝对防御”等无承载上限的描述不得进入正式设定。

## 二、能力分类

能力按主要作用对象和核心变量分类，不按强弱或觉醒批次分类。

| 系别 | 核心作用 | 常见变量 | 边界 |
|---|---|---|---|
| 形态系 | 改变自身身体结构 | 硬度、弹性、器官形态、体表结构 | 不能凭空增加无限质量 |
| 运动系 | 改变自身或接触物的运动状态 | 速度、惯性、方向、冲击传递 | 不能无代价改变大范围重力 |
| 感知系 | 接收常规感官外的信息 | 应力、蓝光、情绪、生理准备 | 不能创造信息或读取完整未来 |
| 生理系 | 调节生命体内部过程 | 代谢、痛觉、凝血、体温、分泌 | 不能无代价复活或完全治愈 |
| 物质系 | 改变无生命物体的一项材料属性 | 硬度、摩擦、导电、脆性 | 不同时改写组成、质量和全部性质 |
| 精神系 | 处理已有意识内容 | 情绪、注意、感官、短期记忆 | 不能凭空创造信念或重写完整人格 |
| 共生系 | 建立生命之间的有限连接 | 信号、感官、资源、痛觉分配 | 必须存在可追踪的连接媒介 |
| 场域系 | 在有限区域改变一种可测条件 | 声音、光、蓝光沉积、方向感 | 一次只能维持一个主效果 |
| 元素系（表现层） | 火、冰、雷、风、雾、砂、金属、蒸汽等高可视化战斗表现 | 依具体契约确定 | 通常归入物质系/运动系/场域系，不可凭空造元素 |
| 异常表现 | 两个以上系别形成的罕见复合能力 | 依具体契约确定 | 不作为规避限制的兜底分类 |

阶位与分类的关系：一阶常见形态、生理、感知；二阶开始稳定出现运动、物质、精神、共生；三阶允许同一核心能力出现复合表现；四阶才能形成稳定场域；五阶属于锚点化的规则覆盖，不作为常规能力设计。

元素系不是独立底层分类，而是战斗中最容易被读者直观看见的表达层。它要求能力具备明确介质和明确变量，例如温度、相态、压力、导电性、流速或密度变化；若无法回答“元素从哪里来、靠什么传播、如何被克制”，就不能写成正式设定。

## 三、能力契约字段

| 字段 | 必填内容 |
|---|---|
| 能力名称 | 便于叙述和记录的名称 |
| 能力系别 | 形态、运动、感知、生理、物质、精神、共生、场域或异常表现 |
| 核心意志 | 觉醒时真正想达成的一句话，不写抽象口号 |
| 作用对象 | 自身、单一生命、群体、单一物体或有限区域 |
| 核心变量 | 只能选择一个主要变量，如速度、硬度、痛觉、方向、温度 |
| 触发条件 | 接触、视线、声音、月光、生理状态或其他必要条件 |
| 作用范围 | 接触、距离、视线范围或固定场域大小 |
| 持续时间 | 单次效果、可否维持、可否叠加 |
| 能量消耗 | 受质量、距离、复杂度、持续时间中哪些因素影响 |
| 使用代价 | 饥饿、疲劳、疼痛、器官损伤、侵蚀或认知偏差 |
| 失败方式 | 无效、偏移、反噬、误伤或产生错误信息 |
| 可观测痕迹 | 使用前后留下的客观证据 |
| 外部克制 | 普通技术、环境条件、心理训练或其他能力的克制方式 |
| 进阶方向 | 一阶到四阶能如何增强，但不能跳出核心变量 |
| 禁止事项 | 明确不能做到什么，防止剧情临时越界 |

## 四、现有能力示例

### 4.1 伪预知

| 字段 | 契约 |
|---|---|
| 能力系别 | 感知系 |
| 核心意志 | 在危险真正发生前察觉并避开它 |
| 作用对象 | 自身；间接感知视线内目标 |
| 核心变量 | 即将发生的生理/能量变化 |
| 触发条件 | 目标已经开始做出决定或身体已经进入行动准备 |
| 作用范围 | 视线内约 30 米；熟悉目标可略微扩大 |
| 持续时间 | 预警提前数秒至数十秒，不能连续锁定未来 |
| 能量消耗 | 目标越多、行为越复杂，消耗越高 |
| 使用代价 | 偏头痛、失眠、把可能性误认成确定事件 |
| 失败方式 | 对随机事件、尚未形成的决定和纯机械故障无效 |
| 可观测痕迹 | 瞳孔短暂泛蓝，使用者会出现不自主闪避动作 |
| 外部克制 | 随机行动、多人协同、无预兆的远程攻击、遮挡视线 |
| 进阶方向 | 提高预警时间和目标数量，不获得真正的未来视野 |
| 禁止事项 | 不得读取完整未来、改变因果或保证预测必然发生 |

### 4.2 残留读取

| 字段 | 契约 |
|---|---|
| 能力系别 | 感知系 |
| 核心意志 | 找到物体经历过的关键片段，理解它发生过什么 |
| 作用对象 | 单一物体 |
| 核心变量 | 蓝光或强烈情绪留下的结构回声 |
| 触发条件 | 必须持续接触；物体必须保留原始结构的一部分 |
| 作用范围 | 接触物体及其直接承载的局部痕迹 |
| 持续时间 | 每次读取只能获得一个片段，不能连续播放完整历史 |
| 能量消耗 | 物体越大、历史越久、信息越复杂，消耗越高 |
| 使用代价 | 触觉和他人情绪残留混入自身记忆 |
| 失败方式 | 得到碎片、错序感官或完全无关的结构噪声 |
| 可观测痕迹 | 接触部位出现蓝色细纹，使用者短暂失去当前时间感 |
| 外部克制 | 清除表面、熔毁、粉碎、隔绝接触、制造大量同质噪声 |
| 进阶方向 | 从单一片段提升到同一事件的多个片段，不获得全知记录 |
| 禁止事项 | 不能读取物体的全部历史，不能读取不存在于物体中的信息 |

### 4.3 物质软化

| 字段 | 契约 |
|---|---|
| 能力系别 | 物质系 |
| 核心意志 | 让阻挡自己的东西暂时失去硬度 |
| 作用对象 | 单一无生命物体 |
| 核心变量 | 表面硬度 |
| 触发条件 | 必须接触，且目标结构必须被使用者理解到基本组成层面 |
| 作用范围 | 接触点半径不超过 30 厘米 |
| 持续时间 | 数秒至一分钟，离开接触后快速恢复 |
| 能量消耗 | 材料越厚、越坚硬，消耗越高；不能穿透无限厚度 |
| 使用代价 | 手指骨痛、局部皮肤角质化、短暂触觉迟钝 |
| 失败方式 | 只软化表层、软化不均导致崩裂或反弹 |
| 可观测痕迹 | 目标表面出现蓝色雾纹和异常温升 |
| 外部克制 | 复合材料、持续振动、隔热隔离、让目标保持运动 |
| 进阶方向 | 提高厚度或作用速度，不同时改变密度、温度和化学成分 |
| 禁止事项 | 不能凭空改变物质组成，不能直接软化生命体内部器官 |

### 4.4 根网共生

| 字段 | 契约 |
|---|---|
| 能力系别 | 共生系 |
| 核心意志 | 让分散的生命共同感知危险并共享资源 |
| 作用对象 | 植物根系、菌根和有限数量的共生生物 |
| 核心变量 | 信号传递与资源分配 |
| 触发条件 | 必须存在连续根系、菌根或体液/组织连接 |
| 作用范围 | 由地下网络决定，不能隔空连接无关植物 |
| 持续时间 | 数分钟至数小时；网络越大越不稳定 |
| 能量消耗 | 节点数量、距离和传输资源量决定消耗 |
| 使用代价 | 使用者逐渐失去个体边界，出现植物化反应 |
| 失败方式 | 信号延迟、错误目标、局部节点过载或全网短暂瘫痪 |
| 可观测痕迹 | 植物同步转向、根系蓝光脉动、空气中出现特定气味 |
| 外部克制 | 切断根系、杀灭菌根、干燥土壤、隔离节点 |
| 进阶方向 | 增加网络稳定性和节点数，不形成完整人格或跨星球意识 |
| 禁止事项 | 不能让森林像人一样连续对话，不能凭空控制没有网络联系的植物 |

| 潮穴巨蜈群 | 管线迁巢 | 共生/形态 | 群体化学信号与甲壳硬度 | 依赖高湿地下管线，不能形成人格 | 干燥、高温和断管会使群体分散 | 生态样本 |

## 六、能力审核清单

新能力进入正式世界观前，必须确认：

- 是否只有一个核心变量？
- 是否明确了作用对象和范围？
- 是否有能量消耗和身体代价？
- 是否会产生可调查的客观痕迹？
- 是否存在可靠克制方式？
- 是否会让侦查、悬疑或战斗失去意义？
- 是否仍然来自觉醒者的核心意志，而不是作者临时需要？
- 是否能解释动物和植物版本的变体？

任一问题无法回答时，该能力只能作为“待验证异常”，不能写成稳定规则。
