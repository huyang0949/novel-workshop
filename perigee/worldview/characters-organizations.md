# 人物与组织讨论底稿

> 本文用于讨论主要人物、组织和关系，不是已确认的剧情事实。除非标记为“已确认”，其余内容均为待讨论项。

## 一、当前已确认的世界约束

- 力量来自月球黑石经调制后的蓝光。
- 所有生命共享同源觉醒机制，但感应度、意志度和容纳度不同。
- 高密度共鸣区是重要资源点，会提高充能效率，也会提高侵蚀速度。
- 觉醒者不能通过击杀或吞噬其他觉醒者获取能量。
- 植物可以通过根系、菌根和化学信号形成有限行动网络，但没有完整人格。
- 祂降下能量是出于好奇和观测，完成观察后会离开。
- 正篇在祂离开时结束，不展开新的能力者时代。

## 二、人物设计总原则

每个主要人物至少需要明确：

1. **表层目标**：人物主动追求的具体结果。
2. **深层需求**：人物真正需要面对的心理问题。
3. **核心意志**：觉醒时最想达成的一句话，决定能力方向。
4. **能力契约**：能力必须符合 [能力契约表](ability-contract.md)。
5. **侵蚀表现**：力量如何改变其情绪、认知、身体或关系。
6. **不可越过的底线**：人物在什么情况下会拒绝某种选择。
7. **关系压力**：至少一段会迫使人物改变的关系。
8. **结局选择**：在祂离开前，人物最终保留、放弃或承认什么。

### 3.1 主角必须先确定的事项

- 故事开始时，主角是普通人、第一波觉醒者，还是调查觉醒事件的普通人？
- 主角是否在引子“月亮眨眼”时就留下了异常？
- 主角的核心意志属于保护、逃离、控制、复原、证明还是理解？
- 主角是否愿意主动使用能力，还是试图拒绝蓝光？
- 主角与高密度共鸣区的关系是什么：发现者、守护者、受害者还是争夺者？
- 主角最初相信哪一种解释：进化、污染、神迹、自然异常或政府阴谋？

## 四、人物功能位

### 4.1 主角

建议承担三条线：

- **外在线**：调查或处理持续扩大的觉醒事件。
- **内在线**：在变强和保留自我之间做选择。
- **认知线**：从“人类中心的灾难解释”逐渐认识到，祂甚至没有恶意，也没有把人类当作对手。

### 4.2 镜像人物

与主角拥有相似核心意志，但做出不同选择。例如：

- 主角选择限制力量，对手选择主动拥抱侵蚀。
- 主角想保护一个具体的人，对手想保护一个群体或物种。
- 主角想理解祂，对手认为理解本身就是背叛人类。

镜像人物不应只是“更坏的主角”，而应在某个关键问题上比主角更有道理。

### 4.3 普通人锚点

至少保留一名不具备战斗能力的普通人，用来体现：

- 觉醒事件对日常生活的影响；
- 普通人如何看待觉醒者；
- 主角失去普通生活后究竟失去了什么；
- 祂观察的对象不只是能力者，也包括未觉醒的人类。

### 4.4 终局见证者

可以是主角、记录者、失去语言能力的觉醒者，或一个与植物网络连接的人。其功能不是解释祂，而是让读者经历“被观察”的荒诞感。

## 五、组织登记表

### 5.1 归序者

| 项目 | 当前设定 |
|---|---|
| 核心理念 | 觉醒是灾难，世界应回到黑石出现之前 |
| 主要目标 | 阻止主动觉醒、研究封禁方法、最终摧毁黑石 |
| 资源来源 | 待补充 |
| 核心人物 | 待补充 |
| 与主角接口 | 可能提供限制蓝光的方法，也可能主张提前处理高能量觉醒者 |
| 内部矛盾 | 自救互助派 vs 觉醒者清除派 |

### 5.2 庇护所

| 项目 | 当前设定 |
|---|---|
| 核心理念 | 力量中性，觉醒者应在保有自我的前提下共存 |
| 主要目标 | 救助新人、训练能力、监测侵蚀、保护成员隐私 |
| 资源来源 | 待补充 |
| 核心人物 | 待补充 |
| 与主角接口 | 提供安全据点、能力训练和情感归属 |
| 内部矛盾 | 公开登记派 vs 隐匿保护派；延缓侵蚀派 vs 主动使用能力派 |

### 5.3 新月教

| 项目 | 当前设定 |
|---|---|
| 核心理念 | 蓝光是恩赐，侵蚀是与神合一的道路 |
| 主要目标 | 扩大信仰、寻找聆听者、主动接近终局 |
| 资源来源 | 待补充 |
| 核心人物 | 待补充 |
| 与主角接口 | 诱惑、绑架、误读主角能力或将主角视为使徒 |
| 内部矛盾 | 等待降临派 vs 主动促成降临派；慈善布道派 vs 极端仪式派 |

### 5.4 深潜会

| 项目 | 当前设定 |
|---|---|
| 核心理念 | 理解祂，不崇拜，也不对抗 |
| 主要目标 | 研究梦境、寻找其他锚点、整理观测记录 |
| 资源来源 | 待补充 |
| 核心人物 | 待补充 |
| 与主角接口 | 提供关键真相，但隐瞒其代价和终局信息 |
| 内部矛盾 | 纯观察派 vs 主动实验派；保护人类派 vs 认为人类只是样本派 |

### 5.5 UNSAD、JIC 与特事司

这三个机构需要明确权限边界，避免功能重复：

| 机构 | 建议定位 | 主要问题 |
|---|---|---|
| UNSAD | 国际协调、数据共享、伦理框架 | 没有直接执法权时如何推动成员国合作 |
| JIC | 跨国调查、情报和反制技术 | 与 UNSAD 的汇报链、越境权限和责任归属 |
| 特事司 | 中国境内登记、处置和地方执行 | 强制管理与觉醒者权益之间的冲突 |

建议让三者在某个案件中产生明确冲突，而不是都成为“政府组织”。

## 六、组织关系矩阵

| 关系 | 公开态度 | 实际合作 | 根本冲突 |
|---|---|---|---|
| 归序者—庇护所 | 互相尊重但理念不同 | 交换侵蚀情报、救援新人 | 是否应该保留觉醒能力 |
| 庇护所—特事司 | 半合法合作 | 报备据点、交换危险名单 | 成员隐私与强制登记 |
| 新月教—深潜会 | 互相利用 | 交换梦境和仪式信息 | 崇拜祂还是研究祂 |
| JIC—深潜会 | 否认存在 | 情报渗透和秘密交易 | 谁拥有终局资料 |
| 特事司—归序者 | 公开不承认 | 个别行动者提供线索 | 是否允许私自处置觉醒者 |
| JIC—新月教 | 公开敌对 | 渗透、诱捕、舆论控制 | 宗教自由与超常风险 |

## 七、主要人物与组织的设计顺序

推荐按以下顺序确定：

1. 主角的职业、初始状态和核心意志。
2. 主角第一次能力失控及其直接后果。
3. 与主角形成镜像关系的主要对手。
4. 一名普通人锚点和一名组织代表。
5. 第一卷实际登场的两个组织，其他组织先保持背景存在。
6. 根据人物选择再细化组织内部派系，不要一开始把所有组织成员都写满。

## 八、当前待确认问题

- 主角是否在第一章就觉醒？
- 主角的核心意志是“保护某人”、 “阻止某事”还是“理解某种真相”？
- 第一卷主视角更偏普通人调查、觉醒者求生，还是政府行动？
- 主要对手来自新月教、归序者、深潜会，还是一个不属于任何组织的个人？
- 第一卷需要同时出现几个组织？
