## 二、世界观设定

### 2.1 迷雾世界

- 世界以**离城**等"孤岛"构成，孤岛之外是浓雾，无法穿越
- 孤岛人口约450万，其中真正的**觉醒者人类**不足500人
- 官方交通（飞机、火车、高速）连接着其他孤岛，彼此隔绝
- 孤岛外的一切（其他城市、国家、历史、文化）大多是虚假的"背景板"

### 2.2 苍道（Cang Dao）

- 统治这个世界的至高法则/意志
- 创造了迷雾世界的一切规则
- 具备修正BUG的能力（删除/修改超出设定的信息）
- 可能曾是"真实世界"的残留意志

### 2.3 孤岛的本质

- 每个孤岛都是一个"囚笼"，圈养着兽群
- 社会系统精密运转，存在完整的现代文明表象
- 迷失者（痴兽）扮演人类，维持社会运转
- 觉醒者的出现是系统的BUG

### 2.4 符文回路（Rune Circuit）

- 共12块，散落在"符洞"（特殊空间）中
- 每块对应一种天赋系别（元素、时空、生命、精神等）
- 收集全部12块可打开**终焉之门**
- 符文回路可用于天赋升级（4级以上必需）和借租使用

目前已出现的符文：
1. **火焰符文**（古家村）→ 强化元素系
2. **时空符文**（牛场站7号线）→ 强化时空系
3. **沉默符文**（11中）→ 辅助系，可集体封印天赋
4. **召唤符文**（11中，符尸BOSS李庄湖身上）

## 三、天赋系统

### 3.1 天赋序列

天赋共199个，按强度从序列199（最弱）到序列1（最强）排列，分十大系：

| 系别 | 特点 | 代表天赋 |
|------|------|----------|
| **神迹系** | 最稀有、最神秘 | 幸运(#199)、净化(#67)、NPC(#110)、血咒(#104) |
| **时空系** | 空间与时间操控 | 瞬移(#19)、飞行(#29)、重力(#31) |
| **元素系** | 操控自然元素 | 火焰(#26)、雷电(#23)、冰霜(#25) |
| **伤害系** | 纯粹攻击 | 杀人专家(#11)、刀神(#32)、枪神(#41) |
| **生命系** | 治疗/再生 | 治疗(#45)、自愈(#47)、壁虎(#42) |
| **精神系** | 精神/心灵操控 | 读心术(#49)、美梦(#50)、传音(#51) |
| **强化系** | 身体强化 | 野兽(#59)、跳跃(#60)、臂力(#76) |
| **守护系** | 防御/保护 | 绝对防御(#9)、铁人(#69) |
| **辅助系** | 支援/控制 | 状态(#77)、隐身(#37)、哑巴(#63) |
| **召唤系** | 召唤生物/物体 | 兽王(#54)、鸟王(#62)、海王(#48) |
| **知识系** | 知识/信息 | 复制(#18)、先知(#5)、识谎者(#181) |
| **毒素系** | 毒/腐蚀 | 醉拳(#57)、蛛毒(#70) |

### 3.2 天赋等级

- 1-3级：可通过训练和领悟提升
- 4级以上：需要**符文回路**共振升级
- 序列100后的天赋最多升到4级（瓶颈）

### 3.3 高阳的系统

- 高阳拥有独一无二的**系统**
- 核心机制：**幸运点**（随时间/杀敌/危险自动累积）
- 幸运点可分配至六维属性：体力、耐力、力量、敏捷、精神、魅力、运气
- 幸运点收益倍数：遭遇危险时翻倍，最高可达5000倍+（遭遇初雪时）
- 可在**天赋神殿**领悟新天赋（消耗幸运点）
- 系统功能：查看属性、复制天赋、危险预警

## 四、兽的分类

| 类型 | 等级 | 特征 |
|------|------|------|
| **痴兽**（迷失者） | D级 | 占99%，以为自己是人类，扮演社会角色，自动修正BUG |
| **嗔兽** | C级 | 主动攻击型，包括：杀伐者（战士型）、吞噬者（触手型）、号角者（领袖型，可唤醒其他兽） |
| **贪兽** | 不定 | 寄生者（寄生于觉醒者）、寄宿者（可成为半人） |
| **妄兽** | B-A级 | 最聪明，接近完全理智，包括：光临者、至暗者、观察者（如初雪） |
| **生兽** | 未知 | 未详细说明 |
| **死兽** | S级 | 最强，共七只，第五部末尾正式苏醒 |
| **符尸** | 不定 | 被符文回路异化的特殊兽，无理智，可被BOSS控制 |
| **半人** | 不定 | 觉醒者被贪兽寄宿后形成的特殊存在 |

### 兽的繁衍假说

- 兽不存在人类生殖系统
- 推测存在"兽皇"（类似虫族母皇），批量生产编号化的兽
- 每个兽有唯一编号，死亡后可被"重印"
- 这就是为什么牛轩（现代）和李庄湖（18年前）外貌完全一致

## 五、主要组织

### 5.1 十二生肖（Chinese Zodiac）

- **领袖**：龙（天赋极强，精神操控/时空暂停，实力深不可测）
- **副队长**：斗虎（天赋【杀人专家#11】，实力排名第9）
- **成员**：白兔（跳跃）、天狗（飞行/空间切割）、萌羊（治疗）、死猪（防御）、歌姬（安魂曲）、青灵（刀神）、黄警官（枪神）、高阳（黑马）、鬼马（内奸，已处决）、蛇（已故）
- **总部**：千禧大楼-F6
- **风格**：精英小团队，纪律严格，实力强劲

### 5.2 麒麟工会（Kirin Union）

- **领袖**：麒麟（深不可测，真实身份和天赋成谜）
- **四圣长老**：
  - **青龙**：负责情报
  - **白虎**：负责行动
  - **朱雀**：生命系大佬，可审问/复活死者（真名夏离）
  - **玄武**：实力派演员晏风，负责内部事务
- **规模**：50+觉醒者，三大组织中最强
- **分部**：十龙寨（总部），按四圣兽分四部

### 5.3 百川团（Hundred Rivers）

- **领袖**：李夫人（真实身份不明，有预测能力）
- **成员**：100+，多为序列100后的低天赋觉醒者
- **风格**：抱团取暖，擅长情报搜集、道具制作、搜寻
- **重要成员**：陈萤（3组长）、王飞（老王，已牺牲）、程鑫（2组长，自私，已牺牲）

### 5.4 鬼团（Ghost Group）

- 最神秘的危险组织
- 成员被称为"鬼"，实力保底=斗虎级别
- **初雪**：银发红眼少女，鬼团成员，跟高阳有多次诡异互动
- **初雪姐姐**：更可怕的鬼，未正式出场

### 5.5 苍母教（Cang Mu Cult）

- 崇拜"苍之神母"的邪恶组织
- 拥有可让觉醒者变为怪物的药水
- 渗透三大组织多年（鬼马、湘蝶、小刘等）
- 成员构成复杂：觉醒者、寄生者、寄宿者、鬼
- 真实目的不明，可能与兽的源头有关

## 七、剧情分章概述

### 第一部《十二生肖》（第1-113章）

**觉醒篇（1-11章）**  
高阳18岁生日当天，青梅竹马李薇薇兽化攻击他，高阳觉醒系统并获得天赋【幸运】。在精神病院遇到百里弋，获得关键纸条。班主任苏婵是第一个引导者。

**面试与测试篇（12-34章）**  
高阳接触十二生肖组织，通过面试和两轮测试（古家村事件前置），获得【复制】天赋。认识黄警官和青灵，三人组成小队。

**古家村符洞篇（35-53章）**  
第一个符洞探险。全村人重复灭门惨案，高阳等人通过扮演警察融入村庄，最终找到被符文异化的"头发怪"，获得第一块符文回路（火焰），并首次接触"半人"概念。

**入职与成长篇（54-79章）**  
高阳正式加入十二生肖，见十龙寨，了解世界真相（苍道、迷雾、孤岛），结识柳轻盈（情报商人），获得【识谎者】天赋，认识百川团。

**红疯事件篇（80-93章）**  
红疯（天赋【爆炸】）袭击高阳，杀死万思思。高阳首次杀人（杀红疯），种下复仇的种子。龙的登场。

**内奸篇（94-96章）**  
鬼马被龙确认为内奸，在会议室对峙后鬼马刺杀失败，被龙处决。高阳从"实习"转正，代号"黑马"。

**牛场站·时空符文篇（97-115章）**  
第二个符洞探险。7号线地铁变为莫比乌斯环，百川团2组几乎全灭。高阳与斗虎团队清图，发现发光巨树，获得时空符文。老王牺牲。

### 第二部《麒麟工会》（第114-255章）

**过渡篇（第114-128章）**  
万思思葬礼，青灵升级。白猫与初雪现身，高阳得知鬼团存在。家人团聚的温馨日常。龙交给高阳秘密任务。

**转投麒麟工会（第129-154章）**  
柳轻盈接触高阳，透露鬼团情报。高阳借调到麒麟工会担任5组"七影"队长，接手连环杀人案调查。

**连环杀人案篇（第141-150章）**  
菜市场追凶。小刘（寄生者）和罗姐的悲剧。高阳团队首次配合，击杀怪物化的寄生者。接触"苍母教"的概念。

**11中符洞篇（第168-204章）**  
**全作第一个长篇高潮**。11中废弃学校隐藏着第三个符洞，所有人在符洞内天赋被集体沉默（"沉默符文"），变为普通人对抗尸潮。5组和4组十二人配合，最终李庄湖（BOSS）被击杀。

**重大牺牲**：李暗（4组）、修一（4组）、西燃（5组，被符尸咬后尸变）、黑雀（4组）、老乔（4组）牺牲。湘蝶（4组）实为内奸，背叛后死亡。5组只剩下高阳、灰雄、曼蛇、罐头、罗尼五人。

**战后篇（第205-255章）**  
尸体失窃（12具尸体被盗），高阳遇见朱雀（夏离），得知起死回生的秘密。青灵送报警器纽扣。高阳与王子凯组建"94二人组"追查鬼马踪迹。第二部末尾预告：猩红潮汐即将降临。

### 第三部《猩红潮汐》（第256-386章）

**预告与备战**  
三大组织（十二生肖、麒麟工会、百川团）联手应对提前两年的猩红潮汐。高阳执行秘密任务，斗虎等人前往雪国调查苍母教老巢。

（猩红潮汐是兽的大规模暴走事件，类似兽潮/尸潮）

### 第四部《命运之锁》（第387-571章）

**剧情深入**  
高阳进入"黑白之墙"的神秘梦境空间。12块符文开始汇聚，三大组织的野心浮出水面。苏曦（班主任）生下"诅咒之子"咒渊。

**第四部末尾**：高阳与咒渊死战，青灵断臂，十二符文集齐。内战不可避免。

### 第五部《生于黑夜》（第572-1083章）

**内战与死兽**  
三大组织正式分裂。五部末尾，七大死兽正式苏醒，觉醒者陷入最大危机。王子凯被死兽占据成为敌人。百里弋出现，带来破局希望。

### 第六部《终焉之门》（第1084-1304章）

**终局之战**  
百里弋揭示更多真相。终焉之门是否存在的终极追问。迷雾世界的真相逐步揭开。高阳作为人类领袖，面对昔日的朋友和亲人，做出最终抉择。

**结局**：第六部完，正传结束。彩蛋展示了一个平行可能——高阳没有觉醒的平凡世界。

## 八、主题分析

### 8.1 存在的意义

"我是谁？"是全作核心命题。兽以为自己是人，人却活在被兽包围的虚假世界。当你知道自己可能是"克隆体"、"数据"、"游戏角色"时，存在的意义何在？

### 8.2 虚假与真实

世界是虚假的，但爱是真的。这是黄警官的人生哲学，也是贯穿全作的精神内核。柳轻盈、歌姬与鬼马、胖俊与女友……无数CP在虚假世界中找到了真实的情感。

### 8.3 选择与代价

觉醒本身就是一种诅咒——知道真相的人无法回到无知的幸福中。高阳多次面临"知道越多越危险"的困境。

### 8.4 成长与担当

高阳从普通高中生成长为人类领袖，每一次成长都伴随着牺牲和失去。"天庭在那"——即使知道结局可能是回到花果山，齐天大圣依然要大闹天宫。

### 8.5 命运 vs 自由意志

苍道、系统、天赋神殿——一切似乎都被设定好。但高阳的选择证明了：即使是棋子，也可以决定如何走完这一生。
