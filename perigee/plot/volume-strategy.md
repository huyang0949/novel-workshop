# 第1-3卷卷纲

> 本文是 [ten-major-arcs.md](ten-major-arcs.md) 的落地版，先只展开前三卷。
> 当前主舞台城市、新月教公开程度仍未最终确认，因此本卷纲用“主舞台城市”“第一灾变热点”等占位表达。正式写作前再替换成具体地名和地理条件。

## 总体定位

前三卷负责完成三件事：

1. 把“超级月亮 + 蓝磁灾变”从奇观写成现实崩塌。
2. 把“觉醒者”从个体异常写成社会资源。
3. 把周既明从证据型旁观者推成必须承担选择后果的人。

前三卷的核心读者承诺是：世界不是突然进入末日，而是先失去电子文明，再重组生存秩序，最后把人本身变成可以标价的资源。

## 第1卷：断网初坠

**年代范围**：2030-2032  
**建议章数**：1-64 章  
**卷目标**：让读者亲眼看到第一次蓝磁灾变如何摧毁现代秩序，并让周既明第一次在救人与保真之间做选择。

### 一句话主线

第一次超级月亮后，主舞台城市陷入断电、断网、断联，异化潮和建筑事故同时爆发；周既明在救援中发现蓝光沉积痕迹，却因选择先救人而错失一份关键证据。

### 读者承诺

- 第一页有奇观：超级月亮、蓝光、月亮眨眼。
- 第一阶段有灾难：电子设备清空，医院、交通和供水系统同时瘫痪。
- 中段有悬疑：建筑裂缝不是正常受力，而像被某种周期性蓝光改写，且伴随超级异化体出现。
- 过程里有战斗：医院、地下车库、桥梁和避难点都要打，救援不是背景，是持续清剿。
- 元素系能力要在这些战斗里露出手感：火、冰、雷、风、砂这类招式通过地形和介质差异拉开画面。
- 战斗后有代价：幸存觉醒者必须接受理智稳定测试，未通过者会被限制行动甚至隔离。
- 卷尾有结构钩子：周既明救下的人，十年后成为最先公开否认他的人。

### 主冲突

| 冲突层 | 内容 |
|---|---|
| 外部冲突 | 城市救援体系失灵，现场需要立刻判断哪些建筑还能进、哪些区域必须撤，以及哪些异化体必须立刻击杀。 |
| 组织冲突 | 特事司要求封锁现场，媒体和群众要求公开，临时救援队只关心怎么活过今晚，黑市则盯上了异化体残留晶体。 |
| 人物冲突 | 周既明坚持保留证据，但叶岚和贺骁要求先救人。 |
| 内在冲突 | 周既明相信“没有证据就不能下结论”，但灾难现场不给他完整取证时间。 |

### 主要人物位置

| 人物 | 本卷功能 | 弧光起点 |
|---|---|---|
| 周既明 | 事故鉴定者，发现蓝光痕迹的人 | 只信证据，厌恶未经验证的解释 |
| 叶岚 | 急救压力来源，逼周既明先处理活人 | “先止血，别让人死在我面前” |
| 贺骁 | 现场行动和撤离压力 | 讨厌把普通人称为附带损失 |
| 宋微 | 舆论与事实核查视角 | 追第一批异常视频和删帖痕迹 |
| 程观岳 | 特事司接口 | 先让城市运转，再谈完整真相 |

### 四段式结构

#### A段：月亮眨眼，城市断线（1-12章）

- 引子写 2030 年 12 月 24 日超级月亮。
- 全城停电、通信中断、电子设备被清空。
- 周既明在桥梁/高架/医院附属建筑事故现场发现异常裂纹。
- 第一批普通人因误判建筑安全而死。
- 第一批超级异化体在医院和地下停车场出现，临时救援队第一次被迫转入清剿。
- 宋微追踪“超人视频”和“月亮眨眼视频”，发现原始上传源被抹掉。

**段尾钩子**：周既明在一块断裂混凝土中看到不符合受力方向的蓝色冷凝纹。

#### B段：救援失序，证据消失（13-28章）

- 特事司临时征用周既明，要求他协助判断危险建筑。
- 叶岚在临时医院处理大量设备停摆后的伤员。
- 贺骁带队救援，被迫放弃一栋仍有人求救的楼。
- 周既明发现多个事故点的裂纹方向都指向同一个城市区域。
- 救援队与异化体巢穴在同一夜里反复遭遇，战斗成为活路的一部分。
- 贺骁队里一名觉醒救援员战后未通过理智稳定测试，特事司要求立刻带走隔离。
- 他想保留样本，却被现场抢救、火灾和封锁打断。

**段尾钩子**：一份原始样本被程观岳带走封存，周既明只拿到半块替代碎片。

#### C段：第一灾变热点露头（29-48章）

- 周既明把裂纹、停电范围、人员昏迷点位叠图，发现疑似第一灾变热点。
- 顾苔介入，判断城市绿化带和地下根系出现同步应激。
- 宋微找到一个幸存者口供：月亮眨眼时，地面也“眨”了一下。
- 特事司要求封锁第一灾变热点。
- 临时救援组织反对封锁，因为那里刚好是避难路线。

**段尾钩子**：第一灾变热点内一棵树在无风环境下集体朝同一方向偏转。

#### D段：先救人，后失证（49-64章）

- 第二轮余波袭来，第一灾变热点附近建筑出现连锁失稳。
- 周既明判断如果继续取证，可以证明蓝光和结构损伤直接相关。
- 叶岚和贺骁要求他放弃样本，立即指挥撤离。
- 周既明选择救人，关键样本被爆燃和坍塌吞掉。
- 撤离路线被异化体封住，主角团必须打一场近距离突破战才能把人带出来。
- 卷尾，他救下一个少年/少女；对方因周既明的判断活下来。

**卷尾钩子**：尾声跳到十年后，一个公开听证会上，这个被救者站出来说：“周既明当年伪造了蓝光证据。”

### 卷末状态

- 主角得到第一份不完整证据。
- 城市确认存在第一灾变热点，但公开口径仍是“复合型灾害”。
- 周既明第一次承担选择后果：人救下来了，真相少了一块。

## 第2卷：无电重组

**年代范围**：2033-2037  
**建议章数**：65-144 章  
**卷目标**：让断网后的世界重组为庇护所、黑市、修复队和临时权力网络，并让周既明从“判断事故”转为“决定资源去向”。

### 一句话主线

电子文明无法恢复，主舞台城市进入长期无电秩序；周既明围绕第一灾变热点的居住、维修和封锁权展开调查，却因拒绝收留一个女孩，间接制造后来的觉醒者倒卖者。

### 读者承诺

- 灾难不只是一夜，而是成为新生活。
- “能修东西的人”和“能判断危险的人”开始拥有权力。
- 第一灾变热点从灾害现场变成资源地。
- 理智稳定证明成为新的通行证：没有证明的人不能进庇护所、修复队和清剿队。
- 卷尾钩子指向第三卷的觉醒者交易。

### 主冲突

| 冲突层 | 内容 |
|---|---|
| 外部冲突 | 无电时代下，城市开始围绕可住区域、燃料、路线和维修权重新分层。 |
| 组织冲突 | 庇护所、黑市、修复队、特事司争夺第一灾变热点周边控制权。 |
| 人物冲突 | 周既明想按风险分配资源，宋微认为公开透明才是唯一约束权力的办法。 |
| 内在冲突 | 周既明擅长判断物的危险，却不擅长判断人的绝望。 |

### 主要人物位置

| 人物 | 本卷功能 | 弧光推进 |
|---|---|---|
| 周既明 | 资源风险判断者 | 从判断建筑转为判断活路 |
| 宋微 | 公开监督者 | 逼主角面对“信息不公开也会杀人” |
| 叶岚 | 庇护所医疗接口 | 保护病患隐私，与特事司压力冲突 |
| 顾苔 | 第一灾变热点生态异常判断 | 证明蓝光积聚不是背景，而是风险传播通道 |
| 程观岳 | 官方秩序代表 | 既需要周既明，又限制周既明 |

### 四段式结构

#### A段：旧城市，新规则（65-84章）

- 城市形成多个生活单元：临时庇护所、黑市街、修复工坊、人工通信点。
- 周既明被要求评估哪些旧楼、地下设施、桥梁还能继续使用。
- 宋微追查救援物资流向，发现部分物资绕开登记系统进入黑市。
- 第一灾变热点附近建筑恢复速度异常快，也坍塌得更突然。

**段尾钩子**：一处被判定“暂时安全”的避难点，在夜里长出蓝色裂纹。

#### B段：谁来分配活路（85-104章）

- 庇护所要求扩大收容，特事司要求限制第一灾变热点附近人员密度。
- 黑市掌握燃料和机械零件，向修复队施压。
- 周既明提出风险分级方案，但方案会让一批人失去住处。
- 一个流浪女孩请求进入庇护所，她携带第一灾变热点附近的异常样本。
- 周既明因风险判断拒绝她进入核心区域。

**段尾钩子**：女孩离开前把样本摔碎，碎片里露出像植物年轮一样的蓝色纹路。

#### C段：黑市里的第一批价格（105-124章）

- 宋微发现黑市开始出售“蓝光护符”“低纯度能量晶体”“灾变热点通行权”“修复优先权”和伪造理智稳定证明。
- 叶岚发现部分病患不是病，而是初期觉醒、侵蚀和稳定度下滑。
- 顾苔证明地下根系会把蓝光异常传播到更远的居住区。
- 周既明意识到灾变热点不能简单封锁，也不能放任开发。
- 特事司准备强制接管周边街区。

**段尾钩子**：宋微拍到一个黑市中间人用“觉醒概率”给人开价。

#### D段：第一次公开分裂（125-144章）

- 特事司、庇护所、修复队和黑市围绕第一灾变热点爆发正面冲突。
- 周既明提出折中方案：分层撤离、保留样本、限制开发。
- 方案救下一部分人，也让另一部分人认为他站在官方一边。
- 当初被拒绝的女孩被黑市吸收，学会用“谁值得救”这套逻辑反过来给人标价。

**卷尾钩子**：几年后，她以新身份出现，成为第一个公开倒卖觉醒者的人。

### 卷末状态

- 第一灾变热点从事故点升级为可争夺资源。
- 庇护所、黑市、修复队、特事司的关系成型。
- 周既明第一次意识到：理性的风险分配也会制造敌人。

## 第3卷：觉醒标价

**年代范围**：2038-2044  
**建议章数**：145-224 章  
**卷目标**：把觉醒者从“异常个体”写成“社会资产”，并让周既明被迫进入组织谈判，不再只靠专业判断解决问题。

### 一句话主线

觉醒者能力开始被组织、企业和地方势力公开或半公开估值，周既明调查一条觉醒者倒卖链，发现自己第一卷救下的人和第二卷拒绝的人都站到了证据链两端。

### 读者承诺

- 能力不再只是变强，而是会被签约、买断、保护、胁迫。
- 觉醒者家属成为新的控制按钮。
- 理智稳定度成为合同门槛，也成为组织排除、压价和威胁觉醒者的工具。
- 周既明必须学习谈判和布局。
- 卷尾把一个早期配角推成后续组织裁决者。

### 主冲突

| 冲突层 | 内容 |
|---|---|
| 外部冲突 | 觉醒者被按能力、阶位、侵蚀风险、理智稳定度和组织归属估价。 |
| 组织冲突 | 特事司要登记，JIC要接管，庇护所要保护，黑市要交易。 |
| 人物冲突 | 周既明想拆掉交易链，但叶岚担心暴露病患名单，宋微担心证人被追杀。 |
| 内在冲突 | 周既明必须承认：只掌握真相不够，还要有让真相活下来的策略。 |

### 主要人物位置

| 人物 | 本卷功能 | 弧光推进 |
|---|---|---|
| 周既明 | 调查者与谈判者 | 从“我有证据”变成“我需要筹码” |
| 叶岚 | 医疗名单守门人 | 拒绝把病人交给任何组织 |
| 宋微 | 舆论与证人保护线 | 面对公开真相是否会害死证人的困境 |
| 程观岳 | 官方登记压力 | 推进强制登记，但仍保留底线 |
| 第二卷女孩 | 觉醒者倒卖链核心中间人 | 证明主角的旧选择会变成新敌人 |
| 第一卷被救者 | 证词反转者 | 否认周既明，切断关键证据链 |

### 四段式结构

#### A段：能力有价（145-164章）

- 城市出现第一批半公开觉醒者合同：保镖、维修、清障、地下竞技。
- 周既明调查一起“自愿签约”失踪案。
- 失踪者家属得到住房和医疗名额，拒绝配合调查。
- 宋微发现合同里有“侵蚀风险免责条款”和“稳定度自担条款”。
- 叶岚发现失踪者曾在庇护所登记过轻度侵蚀症状，且最近一次理智测试被人篡改。

**段尾钩子**：合同签署人正是第二卷离开的女孩。

#### B段：家属是筹码（165-184章）

- 倒卖链不直接抓觉醒者，而是控制家属、药品、住房、安全名额和稳定证明。
- 特事司要求叶岚交出病患名单，以便统一保护。
- 叶岚拒绝，周既明也无法证明名单不会被滥用。
- 第一卷被救者出面作证，指控周既明当年制造蓝光恐慌。
- 周既明的可信度被打击，无法再凭专业身份调动资源。

**段尾钩子**：被救者证词里出现一个只有当年现场人才知道的细节，说明他背后有人给过完整资料。

#### C段：谈判不是妥协（185-204章）

- 周既明被迫学习用筹码换筹码：样本、名单、撤离路线、公开证据。
- 宋微主张公开整条交易链，叶岚反对，因为名单一公开病患会被抢。
- 程观岳提出官方保护方案，但附带强制登记。
- 周既明找出倒卖链真正的价值核心：不是觉醒者本人，而是“可预测觉醒概率”的评估模型。
- 这个模型来自第一灾变热点长期样本。

**段尾钩子**：模型原始文件上，有周既明第一卷失去的那份样本编号。

#### D段：拆链与标价（205-224章）

- 周既明设局：用伪造的高价值觉醒者名单引出倒卖链买家。
- 行动成功一半，救出部分人，但核心中间人逃脱。
- 宋微保住证据，叶岚保住名单，程观岳得到足够理由建立公开登记制度。
- 周既明接受现实：不能只靠揭露真相，还要设计让真相无法被轻易吞掉的结构。

**卷尾钩子**：第97页事故卷宗里那个不起眼的配角，以“裁决者”身份接管交易链余部，并留下第一句话：“他终于学会谈条件了。”

### 卷末状态

- 觉醒者资产化正式成立。
- 强制登记、庇护所隐私、黑市交易三方长期冲突成型。
- 周既明完成前三卷第一次重要转变：从证据型专家变成会布局的调查者。
