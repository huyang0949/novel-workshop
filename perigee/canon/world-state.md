# 世界状态

## 稳定规则

- 核心源头是黑石锚点与蓝光辐射。
- 超级月亮是力量辐射和蓝磁灾变的窗口期。
- 人类、动物、植物共享同源机制，但感知方式与表现层不同。
- 灵感决定能否感知，意愿影响能力显化方向，侵蚀与失控是长期代价。
- 能力必须写成契约：核心变量、作用对象、触发条件、代价、限制、可观测痕迹、克制方式。

## 写作前检查

- 本章是否改变了城市基础设施、舆论、官方行动或黑市行为。
- 本章是否引入新的能力表现；如果是，是否已有能力契约。

- 本章结尾的世界状态是否需要写入 `timeline.md` 或 `open-hooks.md`。
