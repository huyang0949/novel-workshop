# canon 入口

`canon/` 保存已经确认进入正史的稳定资料。AI 写作、审稿和修订前，应优先读取本目录，再按需要回到 `worldview/`、`plot/`、`workflow/model/` 查细节。

## 文件分工

| 文件 | 作用 |
|---|---|
| [book-profile.md](book-profile.md) | 作品定位、题材承诺、叙事基调和读者体验 |
| [characters.md](characters.md) | 已确认人物与组织入口，详细设定引用原始资料 |
| [world-state.md](world-state.md) | 当前世界状态、时间线、社会秩序和能力规则 |
| [open-hooks.md](open-hooks.md) | 已埋但未兑现的伏笔、悬念和风险 |
| [timeline.md](timeline.md) | 正史时间线与章节摘要索引 |

## 使用规则

- `canon/` 只记录已确认内容；脑暴、候选路线和未定设定放入 `workflow/forecasts/` 或 `workflow/working/`。
- 写作输出不能自动改写 `canon/`；只有用户确认采用后，才把结论同步进来。
- 发现 `canon/` 与 `worldview/`、`plot/` 冲突时，先记录冲突，不要自行合并。
